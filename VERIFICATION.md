# KARI 固件验证

**语言 / Language:** [简体中文](#简体中文) · [English](#english)

## 简体中文

本次 N16R8、N8R8 固件已重新构建，严格跨仓库契约、硬件策略、身份、热点、运动仲裁与本地存储测试通过。安装页 13 项协议测试通过；生成的应用包及全部 USB 分段扫描无历史品牌名称。

2026-10-28，维护者确认既有真机测试全部通过，并授权正式稳定发布。本轮未重新连接实体开发板，不将该确认写成本轮 USB / 电机 / OTA 的实测日志。

完整区分见[统一验证记录](https://github.com/xlle-er/KARI-DF26/blob/main/docs/validation.md)。首次安装需重新配网与确认接线，确认前电机禁用。

## English

Both N16R8 and N8R8 images were rebuilt. Strict cross-client contracts, hardware policy, identity, hotspot, motion arbitration and local storage tests passed. All 13 installer protocol tests passed; application and USB segments passed the historical-brand scan.

On 2026-10-28, the maintainer confirmed prior physical-device tests and approved the stable release. The migration check did not rerun physical USB / motor / OTA acceptance; that confirmation is not represented as a newly executed log.

See the [central validation record](https://github.com/xlle-er/KARI-DF26/blob/main/docs/validation.md). A fresh installation requires Wi-Fi and wiring confirmation; motors remain disabled until configuration is confirmed.
